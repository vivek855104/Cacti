# Azure Bay Resort & Spa

An interactive 3D resort tour built with Three.js: a drone view of the grounds and beach, walk-in rooms,
and a day-to-night time-of-day slider. Everything is generated in code, so there are no model or image files.

Open the site, drag to orbit, pick a building, then step inside a room.

Useful URL switches: `?perf` shows a frame-rate overlay, `?nointro` skips the opening fly-in.
